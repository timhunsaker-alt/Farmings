Farm animals live much longer than a Minecraft day, so Farmings runs their lives on a faster clock.

## Two clocks
- **Cattle, sheep, goats, pigs and horses:** **1 game day = 15 real days** (15:1). A Minecraft day is **20** minutes, so a cow's whole
  year takes about **24** game days.
- **Poultry:** **1 game day = 3 real days** (3:1) for every bird.
- **Crops** grow on the 15:1 clock too.

## Output stays real
Each game day an animal gives **one real day's output**: one day of milk, eggs or manure, not fifteen. A hen lays about one real day's
eggs each game day while she ages three days. Machines are sized to real flows.

## Examples
- A cow's gestation of **283** days takes **18.9** game days.
- A cow's heat cycle of **21** days comes round every **1.4** game days.
- Chicken eggs take **21** days to hatch: **7** game days.
- Machine process times also run 15:1: a real 21-day digester cycle takes **1.4** game days.

## What runs in real time
- **Taming:** an animal needs **7** real days settled in a [corral](corral).
- **Food:** shelf lives are real days played as game days, so milk that keeps **7** days in a fridge keeps **7** game days. See
  [spoilage](spoilage).
